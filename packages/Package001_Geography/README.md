# Package001 Geography

## Purpose

Package001 is reserved for ValueWeave's Geography knowledge package. It will hold geography-related data and documentation used to support district intelligence, regional discovery, and future location-aware platform features.

## Expected Contents

This package is expected to contain versioned Geography releases such as:

- District and regional data.
- Administrative geography references.
- Package manifest files.
- Changelogs and release notes.
- Import or integration notes.
- Source documentation where applicable.

## Versioning

Released Geography packages should follow the repository package release format:

```text
Package001_Geography_vMAJOR.MINOR.PATCH.zip
```

The first prepared release is expected to be:

```text
Package001_Geography_v1.0.0.zip
```

Released versions are immutable. Future updates should be introduced as new versioned releases rather than modifying an existing release in place.

Prepared for release upload. This folder intentionally does not include generated Geography data yet. The completed `Package001_Geography_v1.0.0.zip` release can be uploaded here in a later step and reviewed before integration.
