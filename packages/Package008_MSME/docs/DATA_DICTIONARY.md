# Data Dictionary — Package008_MSME v1.0.0

Every column of every dataset, with the value domain **actually observed in the released CSVs** — not an intended schema. Generated by `build_docs.py`; regenerate rather than edit.

**18 datasets · 477 records · 7770 cells · 40 businesses · 289 sentinel (3.72%)**

## Conventions

| Term | Meaning |
|---|---|
| **PK** | Primary key — unique and non-empty, enforced by check V2 |
| **FK** | Foreign key — resolves in-package (V8) or upstream (V9) |
| **sentinel** | The bare string `PENDING_VERIFICATION` |
| **enum** | Small closed set; full observed domain listed. Eleven are enforced by V12 |
| **ordinal** | Ranked but not measured — comparable between rows, not a quantity |

### The six provenance columns

Present on all 18 datasets with identical semantics, documented once here:

| Column | Type | Meaning |
|---|---|---|
| `data_source` | text | Ministry, authority or association the row is attributed to |
| `source_url` | url | Public URL for that body |
| `collection_date` | date | `2026-07-25` on every row (V7) |
| `confidence_score` | numeric | Integer 0-100, capped at 85 (V4). Observed range 57-78 |
| `verification_status` | enum | `VST-NEEDS_REVIEW` on every row — no human sign-off (V6) |
| `notes` | text | Caveats and sourcing remarks |

### Two kinds of sentinel, and why the difference matters

1. **No public source exists for the fact** — every monetary and duration field: `investment_range`, machinery cost, `typical_payment_cycle`, `typical_lead_time_to_revenue`.
2. **The upstream package holds no counterpart record** — a sentinel in any `package0NN_*_id` column. That is a statement about upstream coverage, not about the relationship being unknown. A sentinelled `package005_machinery_id` means Package005 does not catalogue that machine; the machine itself is named in `machinery_name`.
