Package006 is reserved for Skills knowledge assets. It will eventually support skill catalogs, industrial readiness, training pathways, assessment structures, and mappings between skills, industries, districts, and opportunities.

## Expected Contents

- Industry-to-skill mappings.
- Training and certification mappings.

- Package manifests and changelogs.

## Versioning

Skills releases should use the package release format:

```text
Package006_Skills_vMAJOR.MINOR.PATCH.zip
```

Released package versions are immutable. New or revised skill models should be shipped as new versioned releases.
