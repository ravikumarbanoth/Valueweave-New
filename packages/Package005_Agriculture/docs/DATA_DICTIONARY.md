# Data Dictionary — Package005_Agriculture v1.0.0

Every column of every dataset, with the value domain **actually observed in the released CSVs** — not an intended schema. Generated by `build_docs.py`; regenerate rather than edit.

**16 datasets · 388 records · 6062 cells · 132 sentinel (2.18%)**

## Conventions

| Term | Meaning |
|---|---|
| **PK** | Primary key — unique and non-empty, enforced by validation check V2 |
| **FK** | Foreign key — resolves to another dataset, enforced by V8 (in-package) or V9 (cross-package) |
| **sentinel** | The bare string `PENDING_VERIFICATION`: no public source found for that fact |
| **enum** | Small closed set; the full observed domain is listed |
| **ordinal** | Ranked but not measured; comparable within a row group, not across |

### The six provenance columns

Present on all 16 datasets, identical semantics everywhere, so they are documented once here rather than repeated 16 times:

| Column | Type | Meaning |
|---|---|---|
| `data_source` | text | Authoritative body the fact is attributed to |
| `source_url` | url | Public URL for that body or scheme |
| `collection_date` | date | `2026-07-24` on every row in the package (V7) |
| `confidence_score` | numeric | Integer 0–100, capped at 85 by policy (V4). Observed package range 50–78 |
| `verification_status` | enum | `VST-NEEDS_REVIEW` on every row — no human sign-off yet (V6) |
| `notes` | text | Caveats, qualifications, sourcing remarks |
