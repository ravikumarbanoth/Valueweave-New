# Data Dictionary — Package007_Government_Schemes v1.0.0

Every column of every dataset, with the value domain **actually observed in the released CSVs** — not an intended schema. Generated by `build_docs.py`; regenerate rather than edit.

**15 datasets · 655 records · 10401 cells · 40 schemes · 534 sentinel (5.13%)**

## Conventions

| Term | Meaning |
|---|---|
| **PK** | Primary key — unique and non-empty, enforced by check V2 |
| **FK** | Foreign key — resolves in-package (V8) or upstream (V9) |
| **sentinel** | The bare string `PENDING_VERIFICATION`: no public source found for that fact |
| **enum** | Small closed set; the full observed domain is listed |

### The six provenance columns

Present on all 15 datasets with identical semantics, documented once here:

| Column | Type | Meaning |
|---|---|---|
| `data_source` | text | Scheme portal, ministry or authority the row is attributed to |
| `source_url` | url | Public URL for that body |
| `collection_date` | date | `2026-07-25` on every row (V7) |
| `confidence_score` | numeric | Integer 0–100, capped at 85 (V4). Observed range 60–78 |
| `verification_status` | enum | `VST-NEEDS_REVIEW` on every row — no human sign-off (V6) |
| `notes` | text | Caveats and sourcing remarks |

**Layer** 8 - Recommendation Layer · **PK** `recommendation_id` · **37 records** × 18 columns · **confidence** 60–60 (avg 60.0) · **sentinel** 12 cells

**Foreign keys**

- `scheme_id` → `government_schemes.csv` (`scheme_id`)
- `suggested_next_scheme_id` → `government_schemes.csv` (`scheme_id`)
- `related_scheme_ids` → `government_schemes.csv` (`scheme_id (semicolon-delimited)`)

**Limitations.** Confidence is 60 on every row, the lowest in the package, and deliberately so. priority_score is a designed heuristic, not an empirical outcome measure: no uptake, approval-rate or benefit-realisation data was available to calibrate it. Profiles are archetypes, not real users, and a production recommender must validate against actual eligibility determination rather than trusting these scores. Treat this dataset as a rule-engine seed, not as evidence.
