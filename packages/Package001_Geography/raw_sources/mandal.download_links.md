# Download Links — `mandal` Dataset
*(For manual retrieval by a human Data Steward, since automated access was blocked for every primary source this run.)*

- LGD Sub-District Directory download tool: https://lgdirectory.gov.in/downloadDirectory.do
- LGD dataset on the Open Government Data Platform: https://www.data.gov.in/catalog/local-government-directory-lgd
- Community-maintained LGD mirror (2022 snapshot, dated): https://github.com/planemad/india-local-government-directory
- Latest LGD archive tool (dynamic, by date): https://ramseraph.github.io/opendata/lgd/
- Census of India 2011, Telangana/AP Part-I State Administrative Divisions atlas: http://www.censusindia.gov.in/2011census/maps/atlas/28part1.pdf
- Telangana State Statistical Abstract 2022 (PDF): https://telangana.gov.in/wp-content/uploads/2023/05/Telangana-State-Statistical-Abstract-2022-1.pdf
- Medak district portal, Village & Panchayats section: https://medak.telangana.gov.in/village-panchayats/

**Recommended action:** download any one of the first three items above and upload it directly to a ValueWeave Data Factory session — direct file upload is read locally and is not subject to the robots.txt restrictions that blocked every automated fetch attempt in this run.
